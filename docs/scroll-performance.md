# Scroll and rendering performance

The current source of production measurements is [PERF_REPORT.md](../PERF_REPORT.md). It supersedes the earlier short development-server experiment. Use `npm run test:perf` to build and serve production, measure two 8-second full-page wheel passes plus two 3-second interactions, and save raw metrics in `.local/perf`. Set `PERF_ENFORCE=true` to enforce the interaction thresholds.

Wheel, trackpad and touch scroll natively, without a second inertia curve or wheel multiplier. Lenis only handles explicit 0.4-second anchors. Its virtual wheel listener attaches to an inert element; real input listeners are passive. Input interrupts anchors, and the Lenis clock is rebased before each new anchor to exclude idle time. Global CSS scrolling remains `auto`. ScrollTrigger uses the same native document scroller without a proxy.

One application GSAP scheduler drives Lenis, ElectricLogo, deferred pointer writes, scroll-activity deadlines and adaptive frame monitoring. It sets lagSmoothing(0) and a 120Hz decorative ceiling, suspends subscribers on hidden documents, and releases every component's tasks on cleanup. Native wheel/browser frame delivery remains independent. Framer's transient animations and browser compositor animations retain their own library internals; they are not additional persistent application rAF loops. Business countdown and support-poll timers are unrelated to animation and remain at 1 second / 15 seconds.

ElectricLogo traces the supplied image in a worker. GL rendering remains on the main thread, with ≤30 draws/second, DPR≤1 and a 450,000-pixel budget. Typed fields, uniforms, arc records and render options are reused. Rendering stops while scrolling, hidden, or offscreen; disposal releases textures, geometry, shaders and the context. Parallel shader completion is polled only when the GPU extension exists. First-load compilation still produces long tasks on this machine; see the report's remaining-work section.

MagicBento caches layout coordinates in ResizeObserver. Passive pointer events only record input and enqueue a shared-ticker write. Fixed radial-gradient layers move with transforms. Each grid pools at most 12 particle nodes and 2 ripple nodes; only one hovered card runs particles. Native particle animations pause on leave, scroll, hidden documents and offscreen grids. Layer hints exist only during motion and are cleared on cleanup. Live reduced-motion changes restore reading position after ScrollTrigger's media refresh.

The fixed support orb uses a 192px video with a static poster and no CSS upscale. Playback pauses when hidden/offscreen; static visits do not attach the video source. Normal desktop navbar blur stays at 16px per the user's choice; low-effects mode disables blur, WebGL, particles and ambient masking. Static content and purchase/help controls remain available.

Production regression tests cover exact native wheel displacement, anchor interruption/resize limits, real GL draw counts and framebuffer caps, offscreen/scroll/route cleanup, particle reuse/ripple caps, cached pointer geometry, desktop/mobile layout, guide dialog locking, live preference restoration, device policy and sustained slow-frame degradation. Simulated commerce and receipt tests require development mode and are excluded without weakening the production API lock.
