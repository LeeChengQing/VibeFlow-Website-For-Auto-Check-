## 2. 支付网关手续费测算

### Stripe (以马来西亚本地卡与 FPX 为例)
- **标准费率**：3.0% + RM 1.00 (或 FPX RM 1.00 固定费率)
- **以 Bundle 促销价 (RM 30.00) 测算**：
  - 银行卡手续费：`RM 30.00 * 3% + RM 1.00 = RM 1.90` (占售价 6.33%)
  - FPX 手续费：`固定 RM 1.00` (占售价 3.33%)
  - 净到账：RM 28.10 ~ RM 29.00

### ToyyibPay (FPX 线上网银通道)
- **标准费率**：RM 1.00 / 笔 (视签约费率而定，通常不超过 1.5% 或固定 RM 1.00)
- **以 Extension (RM 24.99) 测算**：
  - 手续费：RM 1.00 (占售价 4.0%)
  - 净到账：RM 23.99

### 368云寄售 (卡网第三方渠道)
- **寄售服务费率**：约为 3% ~ 5%
- **提现费**：通常为 1% 或单笔固定小额费用
- **综合通道损耗**：预估在 4% ~ 6% 之间

## 4. 盈亏平衡点 (Break-Even) 计算

假定平均订单为 Bundle 方案（净收益约 RM 28.00 / 单）：
$$\text{月度平衡单量} = \frac{\text{月度固定成本 (RM 180)}}{\text{单笔平均净利润 (RM 28.00)}} \approx 6.4 \text{ 单}$$

**结论**：每月仅需达成 **7 笔** Bundle 订单（或约 8 笔 Extension 订单）即可完全覆盖全部基础设施与服务固定开支。其余收入除预留 **5% 退款准备金** 外，均为净现金流。
