## 1. 数据收集最小化原则
Auto-Check 严格贯彻数据收集最小化（Data Minimization）与本地优先（Local-First）原则：
1. **不收集教务密码与登录凭据**：扩展端在浏览器本地执行，绝不向服务端上传用户的教务系统学号、密码、认证 Token 或 Cookie。
2. **设备指纹脱敏**：激活许可证时，客户端仅生成随机 UUID 并单向哈希后发送至服务端用于绑定计数，不读取 MAC 地址、IMEI 或硬件序列号。

## 2. 交易与同意日志留存
为履行反洗钱、税务与支付卡争议抗辩（Dispute / Chargeback）的法定合规义务，下单结账时系统自动留存以下审计字段：
- 填写的交付邮箱；
- 购买方案与订单参考号；
- 条款版本标识（`terms_version`）；
- 同意时间戳（`terms_accepted_at`）；
- 单向加盐哈希的买家 IP 地址（`consent_ip_hash`）；
- 浏览器用户代理字符串（`consent_ua`）。

## 3. 数据存储与安全
所有敏感数据及许可证均采用 AES-256-GCM 服务端加密并严格执行行级安全策略（RLS），任何非特权公开角色均不可跨订单检索数据。

## 4. 数据删除与权利
用户可随时通过客服工单系统申请查询其关联订单的状态或请求在法定留存期届满后擦除其非财务必要数据。
